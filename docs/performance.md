# 公会业绩表

统计页的「均值偏差」入口替换为本地业绩表，不再打开失效外链。业绩表独立于整体视觉改版，可以单独部署。

## 计分

沿用已有群内「业绩表」规则：整刀基础分为 1；尾刀、补偿刀伤害达到公会阈值为 1，否则为 0.5。代刀记录归属于 `behalf` 指定的人。

每刀业绩分 = 基础分 × 生效权重。未设置单刀权重时使用该周目对应的阶段权重；设置后使用单刀权重，完全替代阶段权重。权重允许 0 至 100，阶段权重最多一位小数，单刀权重最多四位小数；0 表示不计分。半分乘权重可能产生第五位小数，汇总和显示保留该精度。

成员排名列依次为总刀数、B/C/D 阶段刀数、B/C/D 得分、总业绩分。阶段从 B 开始，第 1 周属于 B；按档案配置的周目范围划分，阶段刀数包含整刀、尾刀和补偿刀，代刀计入归属成员。若配置更多阶段，后续阶段列同步展示。CSV 与网页列保持一致。

阶段默认读取当前 Boss 配置，权重默认均为 1。管理员可以修改阶段周目范围、阶段权重、单刀权重以及本档案的尾刀/补偿刀阈值。阶段从第 1 周开始连续排列，并须覆盖档案中所有报刀。

网页与群内命令共用计分服务。群内发送「业绩表」会返回与网页列结构一致的彩色表格图片，标题为「公会名-20xx年xx月-公会战业绩表」。年月取当前档案最近一次报刀的会战日期；档案无报刀时取当前会战日期。网页编辑时立即预览，保存后群内命令同步生效。网页可切换历史档案、搜索明细并导出成员排名 CSV；未保存预览的导出文件名带「预览」。档案统计保留已离会成员的历史报刀，避免退会后历史业绩消失。

## 权限与保存

公会成员可查看；该公会管理员与机器人所有者可修改。其他公会的管理员不因此获得权限。保存接口检查登录、公会权限和 CSRF，并拒绝覆盖其他管理员已经提交的版本。

配置保存在机器人数据目录下 `performance/<公会 ID>/<会战档案 ID>.json`，包含阈值、阶段周目范围和权重。首次保存后，这些规则固定在该档案中，不随以后更新 Boss 配置而变化。尚未保存的档案仍使用当前默认配置。

文件采用临时文件加原子替换写入。单刀配置还保存报刀内容指纹，忽略已删除或内容变化的记录；撤销、清空报刀在数据库提交后清理对应单刀权重，防止记录编号重用导致误计分。清空保留阶段规则和阈值。

备份机器人数据目录时应一并备份 `performance` 子目录。配置文件损坏会给出错误，不会静默回退并改变历史计分。

## 验证

`python -m unittest discover -s tests -q` 覆盖 SQLite 真实报刀计分、代刀归属、阶段/单刀优先级、零权重、精度、档案隔离、权限、CSRF、记录编号重用、历史规则保存和版本冲突。

浏览器验收使用仓库随附 Vue/Element UI 资源，在 1440、768、390 像素宽度检查管理员编辑、即时预览、零权重保存、成员只读和页面宽度，无控制台错误。
